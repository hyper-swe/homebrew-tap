# Homebrew Tap for HyperSWE

Homebrew formulae for [HyperSWE](https://github.com/hyper-swe) tools.

## Install

```bash
brew install hyper-swe/tap/mtix
```

## Available Formulae

| Formula | Description |
|---------|-------------|
| [mtix](https://github.com/hyper-swe/mtix) | AI-native micro issue manager for code-generating LLMs |
